# Atelier — 3D Perfume Bottle Designer

**Design your own perfume bottle in an interactive 3D environment.**

Atelier is a lightweight Windows application for creating and customizing 3D perfume bottles. Experiment with shapes, caps, and labels using an intuitive interface with real-time 3D visualization.

## Features

- **Interactive Shape Editor** — Create and modify bottle silhouettes using editable curves.
- **Real-Time 3D Preview** — Instantly visualize your design.
- **Cap Customization** — Experiment with different cap designs and settings.
- **Custom Labels** — Personalize your bottle with names and labels.
- **Save Projects** — Save your designs for future editing.
